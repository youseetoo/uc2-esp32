## Goal
An intentional, reviewable default IDF config replacing the 50 KB dump on `main_espidf`.

## Actions
1. Replace root `sdkconfig.defaults` with ≤ ~250 commented lines, deliberate choices only:
   - log levels default; main task stack (match PIO's app-main stack); FreeRTOS tick;
   - app version string from git tag; ccache off; `CONFIG_COMPILER_OPTIMIZATION_DEFAULT`.
   - TWAI (keep always on — tiny; `canopen_node` needs it), SPI/I2C/LEDC/PCNT/ADC always on.
   - **BT symbols go ONLY into BT apps' per-app defaults** (T3.x), not the root file.
2. Add `sdkconfig.defaults.esp32` and `sdkconfig.defaults.esp32s3` target overlays
   (IDF picks automatically): flash 40 MHz, partition table name per target; USB-Serial-JTAG
   console for S3 only where the app also sets it (see `../refs/env-app-mapping.md` §3).
3. Do NOT delete the 96 stale `sdkconfig*` files yet — that is T2.11.
