# T1.3 — Build `uc2_hal` shim v1 (Arduino → IDF)

**Phase 1 · Effort 1–2 d · Depends: T1.1 · Gated by: — (D1 affects IDF API availability)**
**Invariants:** dual-build; size ±10 %. Index: `../PORT_PLAN_STEPS.md` · Full API table + port order: `../refs/hal-shim.md`

## Goal
The Arduino-compat shim so existing `.cpp` modules compile with minimal edits (Phases 1–3
stay C++). C core (`hal.c`) + `uc2_hal.h` with C++ façades for `Serial`/`Wire`.

## Actions
1. **Fix the exact surface first** (grep `main/`): `String ` usage count, `ESP.`, `touch*`,
   `analogRead/analogWrite`, `attachInterrupt` edges used, `Wire` transaction patterns.
   Extend the table in `../refs/hal-shim.md` only for APIs that actually appear.
2. Implement `components/uc2_hal/` per the table: time (`esp_timer`), GPIO + shared
   `esp_intr_alloc()` per-pin callback table, ADC1, LEDC PWM, UART v2 `Serial` façade
   (console UART), I2C master v2 `Wire` façade, `esp_random()`, math inlines, `ESP_LOG*`
   mapping for `log_i/w/e`, `esp_restart()`.
3. Mechanical include swap across `main/` (~101 lines): `#include <Arduino.h>` /
   `"Arduino.h"` → `#include "uc2_hal.h"` (scriptable; one commit).
4. Host unit test for the pure parts (time, math, callback table).

## Acceptance
- Host tests for pure parts green.
- A compile-only target proves `Serial`/`Wire`/GPIO façades type-check for both `esp32`
  and `esp32s3`.
- PIO reference build still green (include swap must not change behavior).

## Rollback
Shim is additive; the include swap is one revertable commit.
