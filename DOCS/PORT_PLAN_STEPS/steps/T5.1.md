# T5.1 — Vendor leaves: C-ify `accelstepper`, `onewire_ds18b20`, `encoder`, `tca95xx`, `DAC_Module`

**Phase 5 · Effort 1–2 w · Depends: T4.8 · Gated by: — (D2=(b) confirmed 2026-10-08; scope below is fixed)**
**D2=(b) scope note:** `tmc_stepper` and `fastaccelstepper` stay C++ leaves (recorded in
`DOCS/cpp-leaves.md`); the 5 libs below C-ify.
**Invariants:** dual-build; size ±10 %; vendor behavior unchanged (no upstream fixes smuggled in). Index: `../PORT_PLAN_STEPS.md`

## Rule for all vendor C-ifications
- Copy the vendor source into `components/<lib>/` (already done when vendored in Phase
  2) and C-ify **in place**; keep the original upstream files under
  `components/<lib>/upstream/` (uncompiled, reference only) with a `UPSTREAM.md`
  (version/URL/commit + diff summary). This preserves the "vendor, not fork" audit trail
  the high-level plan requires.
- Behavior invariants: step timing, driver register maps, sensor timing. Re-run the
  relevant `[HW]` checks after each lib.

## Per-lib notes
- **accelstepper** (youseetoo URL fork, AccelStepper backend for xiao_odmr/UC2_3/WEMOS):
  C-ify `AccelStepper` core; re-smoke `apps/xiao_odmr` (stage scan + focus).
- **onewire_ds18b20** (OneWire + DallasTemperature): C-ify; DS18B20 reads must match
  baseline within sensor tolerance; timing-sensitive OneWire bit-bang stays bit-identical.
- **tmc_stepper** (TMC2209/2130 register API): **out of scope under D2=(b)** — stays a
  C++ leaf; record it in `DOCS/cpp-leaves.md` (its SDO status reads are smoke-covered by
  the motor/accelmotor boards).
- **encoder** (ESP32Encoder **0.12.0 — do not upgrade**; master moved to IDF-5 PCNT):
  C-ify; feedback counts unchanged on motor boards.
- **tca95xx** (UC2_3/WEMOS/standalone_v4): C-ify; IO-expander round-trip on uc2_3.
- **DAC_Module** (vendor header used by first-party `DacController` — `DacController.h`
  `#include "DAC_Module.h"`): C-ify the header/impl slice the DAC controllers use;
  MCP4725/SPI DAC register writes unchanged; spot-check DAC output on an app with
  `UC2_DAC_CONTROLLER` (uc2_2 or canopen_master).

## Acceptance
- The 5 libs compile as C; `[HW]` re-smokes pass (odmr, motor, uc2_3, accelmotor, one
  DAC app); `tmc_stepper` + `fastaccelstepper` recorded as D2=(b) leaves in
  `DOCS/cpp-leaves.md`;
  `make test` green; both build systems green; `UPSTREAM.md` committed per lib.

## Rollback
