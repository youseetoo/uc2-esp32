# T4.4 — C-ify `uc2_canopen`; split CANopenModule + DeviceRouter

**Phase 4 · Effort 1–2 w (the phase's longest task) · Depends: T4.2 · Gated by: D2**
**Invariants:** IDF-only (no PIO); size ±10 %; CANopen protocol behavior byte-identical. Conversion rules: see T4.1.md. Index: `../PORT_PLAN_STEPS.md`

## Context
- `components/uc2_canopen/` holds: `CANopenModule` (**138,340 B** — the whole CANopen
  node: NMT/SDO/TPDO/OTA), `DeviceRouter` (**104,132 B** — serial→CAN dispatch + routing
  table), `RoutingTable`, `CanOpenOTA`, `CanOpenOTAStreaming`, `OtaBinaryReceive`,
  `SdoEmit.h`, `UC2_OD_Indices.h`, plus `gpio_can` and `ptz` from Phase 2.
- `canopen_node` (vendor C stack) and `uc2_od` (generated C) are **already C** — don't
  touch them.

## ⚠ Split before converting (the high-level plan's big-bang avoidance)
1. **Step 1 (its own commit)**: split `CANopenModule.cpp` into per-concern files,
   behavior-identical: `canopen_module.c` (task/NMT lifecycle), `canopen_sdo.c`
   (SDO read/write/emit, `SdoEmit.h`), `canopen_tpdo.c` (TPDO mapping/sync),
   `canopen_ota.c` (merge with CanOpenOTA/OTAStreaming/OtaBinaryReceive). Same for
   `DeviceRouter.cpp` → `device_router.c` (routing) + `serial_dispatch.c`
   (serial-JSON→CAN frame translation). No logic changes; verify with a `[HW]` master +
   slave smoke + the suite's CANopen mocks.
2. **Step 2 (commits)**: C-ify each split file per the rules; the OD (`uc2_od`) and
   `canopen_node` interfaces are already C, so the seams are clean.

## Actions
1. Split (step 1), green everywhere, `[HW]` smoke.
2. Convert per file; `make test` after each (CANopen mocks are the suite's strength).
3. `gpio_can` + `ptz` (already in this component) convert in the same pass.
4. Delete Arduino includes; update stubs/CMakeLists.

## Acceptance
- Zero C++ in `uc2_canopen`; all files `.c`.
- `[HW]`: laser + gpio + ptz slaves OPERATIONAL under an IDF master; one SDO + TPDO
  round-trip each; OTA-sender compile-out verified on standalone_v4.
- `make test` green; both build systems green.

## Rollback
Split commit and per-file commits are individually revertable; worst case, revert to the
pre-split monolith (PIO still works via stubs throughout).
