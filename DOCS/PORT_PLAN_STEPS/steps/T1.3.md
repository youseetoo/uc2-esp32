# T1.3 — Convert `main/` to direct IDF (no shim)

**Phase 1 · Effort 3–5 d · Depends: T1.1 · Gated by: — (D1 affects IDF API availability)**
**Invariants:** IDF-only (no PIO); size ±10 %. Index: `../PORT_PLAN_STEPS.md` · Arduino→IDF API mapping: `../refs/hal-shim.md`

## Goal
Convert the `main/` code to direct IDF (no Arduino APIs, no shim). The `main/` code is C++
using Arduino APIs (`Serial`, `Wire`, `String`, `Preferences`, `millis`, etc.). Convert it
to direct IDF calls (UART v2, I2C master v2, `esp_timer`, `nvs`, etc.). No shim layer.

## Actions
1. **Inventory the Arduino API surface** (grep `main/`): `String`, `ESP.`, `touch*`,
   `analogRead/analogWrite`, `attachInterrupt` edges used, `Wire` transaction patterns.
   Record the exact mapping in `../refs/hal-shim.md` (Arduino → IDF).
2. **Convert each module** to direct IDF calls, leaf-first (see port order in
   `../refs/hal-shim.md` §3): time (`esp_timer`), GPIO + `esp_intr_alloc()`, ADC1,
   LEDC PWM, UART v2 (replace `Serial`), I2C master v2 (replace `Wire`), `nvs`
   (replace `Preferences`), `esp_random()`, `ESP_LOG*`.
3. **Remove `#include <Arduino.h>`** / `"Arduino.h"` from all files; add the specific
   IDF headers each module needs (`driver/uart.h`, `driver/i2c.h`, `esp_timer.h`, etc.).
4. **Verify** each module compiles and passes the host unit tests.

## Acceptance
- All `main/` modules compile under IDF 6.1 with no Arduino includes.
- No `#include <Arduino.h>` or `#include "uc2_hal.h"` anywhere in the tree.
- Host tests green; laser app builds and runs on hardware.

## Rollback
Per-module conversion; each commit is independently revertable.
