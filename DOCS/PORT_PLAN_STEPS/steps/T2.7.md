## ⚠ RMT-IRQ ownership (the port's sharpest edge)
- FAS owns the **shared RMT IRQ** (its `setupRMT()` allocates the ISR); Ws2812Rmt uses its
  own channel on the **same** RMT unit. The PIO binary already coexists with this — the
  IDF build must reproduce it: keep FAS as the IRQ owner, WS2812 (if any) on a distinct
  RMT channel, **no second RMT driver installed** (no `CONFIG_RMT_ISR_IN_IRAM` double
  ownership, no LEDC-on-same-channel).
- This app has no WS2812, so it validates FAS standalone first.
