## Goal
The components that are already plain C build under `idf.py` with **zero source changes**.

## Actions (exact moves)
```bash
git mv lib/ESP32_CanOpenNode/src components/canopen_node/    # + lib/ESP32_CanOpenNode/CANopen.h
git mv lib/uc2_od components/uc2_od/
git mv main/cJSON components/cjson/                          # + repoint .gitmodules path
git mv lib/esp_usb_host_hid components/esp_usb_host_hid/
git mv lib/DAC_Module components/dac_module/
```
- `.gitmodules`: submodule path `main/cJSON` → `components/cjson` (DaveGamble/cJSON, master).
- Write a 5–15 line `CMakeLists.txt` per component:
  `idf_component_register(SRCS … INCLUDE_DIRS … REQUIRES …)` — `canopen_node` needs
  `REQUIRES driver` (TWAI); `cjson`/`uc2_od` have no deps.
- Top-level `CMakeLists.txt`: keep `project(...)`; `components/` is auto-discovered.
- **PIO compat**: if a `symlink://lib/…` or `lib_deps` path breaks a PIO build, leave a
  compat symlink `lib/X → ../components/X` **until T6.6** — do not "fix" by moving the
  component somewhere else.
