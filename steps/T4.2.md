## 3. The 4 C++ shims needed (exact scope — host test + canopen_master both only define CAN_CONTROLLER_CANOPEN)

Pattern (per T4.1 `led_strip_c`): in each C++ header, wrap the existing class/namespace in
`#ifdef __cplusplus ... #else ... C shim decls (no extern "C" — it's a C decl) ... #endif`;
in each C++ .cpp, ADD the shim definitions as `extern "C"`. The .c includes these same headers
and sees the `#else` C decls.

1. **DeviceRouter** (`DeviceRouter.{h,cpp}`, uc2_canopen):
   - `.h` `#else`: `cJSON *canopen_routeCommand(const char *task, cJSON *json);`
   - `.cpp`: `extern "C" cJSON *canopen_routeCommand(const char *t, cJSON *j) { return DeviceRouter::routeCommand(t, j); }`
   - (`.c` line 462: `DeviceRouter::routeCommand(task, json)` → `canopen_routeCommand(task, json)`.)
2. **RoutingTable** (`RoutingTable.{h,cpp}`, uc2_canopen):
   - `.h` `#else`: C enums matching the C++ values + `cJSON *routing_table_to_json(void);`
     `void routing_table_set(route_entry_type_t t, int logicalId, route_entry_where_t w, int nodeId);`
     - `route_entry_type_t`: MOTOR=1, LASER, LED, GALVO, HOME, TMC, DAC, AIN, DIN.
     - `route_entry_where_t`: LOCAL=0, REMOTE, OFF.
   - `.cpp`: `extern "C" cJSON *routing_table_to_json(void) { return UC2::RoutingTable::toJson(); }`
     `extern "C" void routing_table_set(route_entry_type_t t, int id, route_entry_where_t w, int node)
       { UC2::RoutingTable::set((UC2::RouteEntry::Type)t, (uint8_t)id, (UC2::RouteEntry::Where)w, (uint8_t)node, 0); }`
   - (`.c` lines 591/626 `UC2::RoutingTable::toJson()` → `routing_table_to_json()`; line 625 `set(...)` →
     `routing_table_set(...)`; `UC2::RouteEntry::MOTOR/LASER/LED/GALVO/HOME/TMC` → `ROUTE_TYPE_*`;
     `UC2::RouteEntry::LOCAL/REMOTE/OFF` → `ROUTE_WHERE_*`.)
3. **CANopenModule** (`CANopenModule.{h,cpp}`, uc2_canopen):
   - `.h` `#else`: `cJSON *canopen_get(cJSON *doc); cJSON *canopen_act(cJSON *doc);`
   - `.cpp`: `extern "C" cJSON *canopen_get(cJSON *d) { return CANopenModule::get(d); }` + `canopen_act`.
   - (`.c` lines 534/536, under `#if defined(CAN_CONTROLLER_CANOPEN)`: `CANopenModule::get/act` → `canopen_get/act`.)
4. **OtaBinaryReceive** (`OtaBinaryReceive.{h,cpp}`, uc2_canopen; namespace, all inside `#ifdef CAN_CONTROLLER_CANOPEN`):
   - `.h` `#else` (inside `#ifdef CAN_CONTROLLER_CANOPEN`): `bool ota_isActive(void); void ota_processBytes(void);`
   - `.cpp`: `extern "C" bool ota_isActive(void) { return OtaBinaryReceive::isActive(); }`
     `extern "C" void ota_processBytes(void) { OtaBinaryReceive::processBytes(); }`
   - (`.c` loop lines 292-294, under `#if defined(CAN_CONTROLLER_CANOPEN) && !defined(CANOPEN_OTA_NO_SENDER)`:
     `OtaBinaryReceive::isActive()/processBytes()` → `ota_isActive()/ota_processBytes()`.)

NOT needed (their `#ifdef` is OFF in both builds, so the blocks are preprocessed out of the .c):
BtController (BLUETOOTH), AnalogOutController/DacController (ANALOG_OUT/DAC), ScannerController
(SCANNER — no component), GalvoController (GALVO), TMCController (TMC — only in `$tmcSrcs`),

## 4. .c conversion (serial/SerialProcessIn.cpp → .c)
- `namespace SerialProcess { ... }` → free functions `SerialProcess_*` (public) + `static`
  file-locals (private). Public (per `SerialProcess.h`): `setup`, `loop`, `addJsonToQueue`,
  `serialize(cJSON*)`, `serialize(int)`; also `processJsonDocument` (public, in header).
  Private → `static`: `serialTask`, `resetSerialFrame`, `reportSerialError`, `jsonProcessor`,
  the frame-parse statics.

  `Serial.setTimeout(100)`→`uc2_serial_set_timeout(100)`; `Serial.available()`→`uc2_serial_available()`;
  `Serial.read()`→`uc2_serial_read()`; `Serial.println("...")`→`uc2_serial_write_bytes(...)` (or
  `serial_out_safe_println`); `ESP.restart()`→`esp_restart()`.
- Keep the `/* KEEP THAT!! */ if (false)` + else-if chain structure (logic unchanged).
- `SerialProcess.h` (the `#ifdef __cplusplus`-only namespace) → add a C decl block
  (`#else`) with the `SerialProcess_*` free functions (so the .c + C callers get the C API).
